# October Index

Explore and rank World Series games using 20 variables. Search by team or game, adjust scoring weights, compare games, and share custom rankings.

This static site runs without a build step. For GitHub Pages, publish the `main` branch from `/ (root)` in Settings → Pages.

Scores and variables come from the author's WS Games spreadsheet snapshot dated November 16, 2026. Team names and final scores were matched against MLB schedule results. Default weights sum to 1; scores are on a 0–100 scale. Custom scores divide by the chosen total weight.

The dataset is a snapshot; spreadsheet changes do not sync automatically.
